# 🔐 SOC Incident Investigation — INV-001

### Simulated Phishing & Account Compromise Investigation

> **Portfolio Project | SOC Level 1 | Incident Response**

⚠️ **Disclaimer:** This is a simulated cybersecurity investigation
created for educational and portfolio purposes. All users, domains,
IP addresses, email addresses, and security events are simulated.

---

## 📌 Project Overview

This project demonstrates a complete **SOC Level 1 incident
investigation** that began with a phishing alert and progressed
through endpoint, authentication, and mailbox analysis.

The investigation identified evidence consistent with a
**likely account compromise** and potential sensitive-information
exposure.

---

## 🎯 Investigation Objectives

- Investigate a suspected phishing attack
- Analyze indicators of compromise (IOCs)
- Determine whether the user interacted with the phishing URL
- Analyze endpoint activity
- Investigate authentication activity
- Investigate suspicious mailbox activity
- Assess potential impact
- Determine incident severity
- Plan containment actions
- Produce a professional incident report
